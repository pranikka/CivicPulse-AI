# CivicPulse AI Demo Dashboard

The bundled database contains a non-destructive demo dataset for demonstrating the Officer dashboard.

## Demo login
- Username: `demo_officer`
- Password: `demo123`

## What the demo shows
The demo officer has 7 sample citizen requests assigned to the account, including:
- 7 assigned requests
- 5 unresolved/pending-work requests
- 1 Critical request
- 3 High/Critical requests
- 2 Resolved requests
- Category and urgency data for the charts
- State/district values for the dashboard filters

The seed script only creates or updates records belonging to the dedicated `demo_citizen` account. It does not reassign requests belonging to real users.
